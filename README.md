# Intel’s Sustainability Timeline

A responsive student project by Jacob Windsor, adapted from the PE Classroom Project 2 starter.

## Open locally

Extract the complete ZIP first. Open `index.html` in your browser. Keep `style.css`, `script.js`, and `img/` beside it. No install or build is required.

## Included

- All nine starter milestones, 1968–2024, and the supplied Intel logo.
- Intel-inspired blue hero, consistent milestone cards, and a Flexbox timeline.
- Horizontal desktop scrolling, vertical mobile stacking, and CSS scroll snapping.
- Hover/focus details plus native expandable controls for touch and keyboard users.
- Previous/next controls, reduced-motion support, visible focus states, and a skip link.
- Five original AI concept illustrations for the sustainability milestones; four starter history illustrations.

## Deployment

This static site is deployed from the `main` branch root using GitHub Pages. No build step or dependencies are required.

## Sources and images

Starter: https://github.com/PE-Classroom/02-prj-intel-sustainability

Culture reflection: https://newsroom.intel.com/corporate/ceo-letter-2023-24-intel-csr-report

Historical claims follow the classroom starter. The 99% electricity figure refers to 2023, not a current live metric. Net-zero by 2040 is a commitment, not a completed achievement. Images are AI concept illustrations, not photographs of real Intel facilities or events. Intel branding belongs to Intel; this is an educational project, not an official Intel website.
